# 📞 Sales and Marketing Call Center Dashboard – Excel Project (Available on request)

## Overview
This Excel-based Sales and Marketing Call Center Dashboard provides actionable insights into agent performance, call outcomes, and customer demographics. It helps stakeholders understand key trends such as total call volume, success rates, agent-level breakdowns, and abandonment reasons

## 📊 Dashboard Features

High-Level KPIs:

Total Calls: 200,000

Successful Calls: 83,519

Failed Calls: 71,837

Abandoned Calls: 44,644

Gender Split: 70% Male, 30% Female

Agent Performance:

Call volumes for top and bottom agents

Drew Clay analysis with metrics such as:

Success rate: 20.2%

Avg. customer score: 4.3

Avg. call length: 15.7 minutes

Call Abandonment Reasons (Drew Clay):

Technical issues (most common)

Wait time, customer hang-ups, agent unavailability

Call Source Geography:

State-wise customer origins for Drew Clay (e.g., Texas, NY, NC)

Product Discussion Outcome (Drew Clay):

Success/failure by product type: Loans, Travel, Internet, etc.

Trend Analysis:

Max and min calls per month for Drew Clay (e.g., peak in December)
